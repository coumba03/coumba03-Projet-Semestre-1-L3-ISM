## 🎯 Animations & Effects

### Transitions
```
Durée Standard: 0.3s ease

Effects:
- translateY(-10px)  → Hover sur cards
- scale(1.02)        → Hover sur boutons
- opacity 0→1        → Slide-up au chargement
```

### Hover States
```
Cards:
  - Border: #ECF0F1 → #E74C3C
  - Background: transparent → #FEF5F3
  - Shadow: 0 4px 15px → 0 15px 35px
  - Transform: translateY(0) → translateY(-10px)

Boutons:
  - Scale: 1 → 1.02
  - Shadow: 0 4px → 0 10px
```

```

  🔒 → click → 👁️ (affiche) → click → 🔒 (masque)

Form Focus:
  Border: #ECF0F1 → Border: #E74C3C
  Shadow: none → Box-shadow: rgba(231,76,60,0.15)

Card Hover:
  Transform: 0px → -10px
  Shadow: small → large
  Border: light → primary

  Scale: 1 → 0.98 (feedback tactile)
```
